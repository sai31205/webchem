# Elemental Chemistry Study Studio

This is a self-contained chemistry learning website with 126 lesson entries and 126 searchable reactions.

## Share it

Send the `elemental-study-studio-share.zip` file to someone. They can unzip it and open `index.html` in any modern web browser.

## Publish it online

Upload the contents of this folder to a static website host such as GitHub Pages, Netlify, or Cloudflare Pages. No server or database is required.

## Contents

- `index.html` — the website structure
- - `styles.css` — design and responsive layout
  - - `app.js` — lessons, reactions, search, and study interactions
